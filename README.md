# Vintage Fashion

A full-stack fashion e-commerce platform built using React, Node.js, Express, and MySQL.

## Tech Stack

### Frontend
- React (Vite)
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Socket.IO
- Cloudinary
- Razorpay
- Resend

## Features

- User Authentication
- Admin Dashboard
- Product Management
- Shopping Cart
- Wishlist
- Checkout
- Razorpay Payment
- Order Tracking
- Notifications
- Email Verification
- Password Reset
- Image Uploads
- Customer Address Management

## Project Structure

```
Vintage-Fashion/
│
├── frontend/
├── backend/

```

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in both frontend and backend using the provided `.env.example` files.
